# HSK3 Sentence Builder — Game Data

Source: every prompt/answer pair is a real question-and-answer exchange taken
directly from the HSK3 textbook's dialogues — same source and same discipline
as the HSK1/HSK2 sentence builder files. 2 exercises per lesson, all 20 lessons.

Decoy tiles are real vocabulary from the same lesson, chosen to be plausible
enough to require actual thought, not obviously wrong filler.

**Note:** as with the vocabulary file, HSK3 doesn't provide official English
translations — the English given here for each full answer is mine, matching
the same translations already used in the vocabulary file for consistency.
