# Colors Vocabulary — Game Data

Source: standard set of basic colors in Mandarin. A few of these already appear
incidentally in HSK2/HSK3 dialogues (红色, 粉色, 白, 黑, 蓝, 绿), but this list
is the complete, standalone set for the Colors game — not tied to any single
book's lesson content, same as the Numbers/Date/Mahjong games in the Games tab.

Hex values are included so the after-answer color swatch renders accurately.

---

## Core colors

- **红色** (hóngsè) — Red — `#E63946`
- **橙色** (chéngsè) — Orange — `#FF8C00`
- **黄色** (huángsè) — Yellow — `#FFD700`
- **绿色** (lǜsè) — Green — `#2ECC71`
- **蓝色** (lánsè) — Blue — `#3498DB`
- **紫色** (zǐsè) — Purple — `#9B59B6`
- **粉色** (fěnsè) — Pink — `#FFB6C1`
- **棕色** (zōngsè) — Brown — `#8B4513`
- **黑色** (hēisè) — Black — `#1C1C1C`
- **白色** (báisè) — White — `#FFFFFF` *(needs a visible border/outline in the swatch since it's a light theme color)*
- **灰色** (huīsè) — Gray — `#808080`

## Bonus/extended colors (optional second batch)

- **金色** (jīnsè) — Gold — `#D4AF37`
- **银色** (yínsè) — Silver — `#C0C0C0`
- **青色** (qīngsè) — Cyan / turquoise — `#00CED1`

## Notes for the game

- All color names follow the pattern **[color character] + 色 (sè, "color")**
  — e.g. 红 (red) + 色 = 红色. Worth mentioning this pattern explicitly
  somewhere in the game (maybe in the intro/instructions) since it's a genuine
  recognizable structure, not just 11 words to memorize independently.
- Accept both the full form ("红色" → "Red") and the bare color character
  alone if the app ever surfaces it that way, though the full 色-form is the
  standard one to teach here.
- 白色 (white) will need a border/outline in its swatch since a pure white
  square would be invisible against a light background — same consideration
  the light/dark mode work should already have flagged for other white/light
  UI elements.
